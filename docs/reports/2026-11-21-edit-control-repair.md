# 2026-11-21 文本控制修复与重训

## 发现的问题

停止并归档 `fei_stage2_repair_20261120` 后，用固定照片和固定种子检查同一检查点：

- strength .65 的源图起点基本保留正脸；把预测几何换成真实目标几何或关掉几何都无明显改变。
- strength1 的纯噪声起点能够左右转头，但身份明显丢失。
- 原训练只在真实目标潜变量上加噪，低噪声输入本来就包含目标动作；实际编辑则从源图加噪开始。这使训练允许去噪而不执行编辑，实际编辑起点没有被直接监督。
- 原图像辅助损失只覆盖 t<500，.65采样从约t621开始，关键的早期编辑步骤缺少该监督。
- 姿态照片的目标/源人脸框通常横向错开45–61像素，而空间几何条件在源框中，造成目标空间冲突。
- 光照照片的完整3D损失有81.3%的原图复制惩罚来自无关表情/姿态差异。缩小原始系数误差不等于按指令调暗像素。

已排除：renderer yaw方向错误（与Deep3D投影差<.000275像素）、空背景法线错误、几何适配器完全为零。未解决的独立渲染近似包括省略Deep3D相机平移（四例约10–12像素偏差）；本次配准不声称修复了该问题。

## 修复

1. 保留普通目标加噪训练，同时把50%的有条件训练样本改为源图加噪。源分支在t250..700使用相对于真实目标的有效噪声标签：

   `effective_epsilon = epsilon + sqrt(alpha/(1-alpha)) * (source-target)`

   因而完美预测时恢复的x0是目标，不是原图。v目标也以目标潜变量计算。丢弃文本的CFG样本不用该源分支，避免无条件矛盾标签。这是受监督的混合编辑目标；单步代数不能保证整个DDIM轨迹，需实际短训和采样验证。
2. 用 `At @ inverse(As)` 把目标照片配准到源人脸框，返回的目标对齐矩阵也改为As；保留原图、缓存和目标3D系数。真实FEI的canonical crop差异约.0025–.0032，证明坐标关系正确。
3. 只约束请求的属性，按实际源→目标位移归一化3D误差。明显编辑下，复制原图损失约1，正确目标为0；不对无关属性的拍摄变化施加目标监督。扩展图像辅助损失到t<700。
4. 光照指令另加共享源对齐脸部裁剪的平均亮度监督，直接惩罚没有可见调光的结果。只影响光照样本，不通过后处理伪造亮度变化。
5. 新增 `--init_checkpoint` 只加载模型权重、重置优化器和训练计数；恢复检查点的配准约定后再加载评估数据，避免比较不同坐标框。

旧配置保持默认关闭新分支，现有检查点结构不变。新配置为 `configs/runs/fei_stage2_control.yaml`。全量运行保留原身份权重.5；短训为.25以诊断控制路径，两者不能当作相同的质量评估。

## 真实短训验证及限制

- 第一轮：8个训练身份的32对照片，400次更新，源图强度.65，35步，CFG1.5。没有使用验证身份参与更新。
- 第二轮：同一小训练集继续200次更新，加入直接亮度监督。不是全量训练或全验证集结果。
- 严格对照：2个未参与短训身份、4种指令，每条指令重新初始化同一个随机种子42；同一身份的源图与初始噪声相同。before是停止的旧检查点，after是上述600步短训模型。

四个左右姿态样例的yaw平均绝对误差：**27.74°→4.64°**，正确方向4/4。四个预测角度从约1.3/1.2/.3/.4变成−31.0/+24.1/−27.8/+19.6，目标为−30.6/+19.4/−35.2/+25.7。

两例“very dim”输出整体归一化RGB均值从约−.071/−.062变成−.160/−.231，出现可见变暗，但仍未达到目标约−.598/−.608。此均值不是独立物理光照评估，背景和肤色也会影响它。

**身份仍有明显偏移**：四个转头例的FaceNet身份余弦均值约.766→.404。微笑有可见响应但3D表情误差未稳定改善。短训只证明控制路径可学习，不能宣称整体质量、身份保持、编辑强度或开放文本泛化已合格。全量运行从此前健康检查点初始化，不从这8个身份的小样本模型初始化，保留身份监督并单独监控各指标。
